Use current AGENTS scope and the repository's executable contracts to resolve
conflicting guidance. Update the conflicting passage rather than adding another
exception above it. Ask only when live requirements remain incompatible or the
decision would change authorized scope.

- Tool discovery and safe fallbacks follow [02-tooling-policy.md](./02-tooling-policy.md).
- Delegation admission follows [AGENTS.md](../../AGENTS.md); useful parallel
  work alone is not admission.
- Validation scope follows [04-validation.md](./04-validation.md). Missing
  evidence blocks only its dependent claim.
- Ordinary Direct Work does not require separate proposer, reviewer, and
  approver roles. Selected audit contracts follow
  [09-audit-trail-policy.md](./09-audit-trail-policy.md).

When removing stale guidance, trace its consumers, repair links, and retain
useful safety requirements in their existing owner. Do not delete a file merely
because a text search found no reference, or present historical receipts as
current requirements.
