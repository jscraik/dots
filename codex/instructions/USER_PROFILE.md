# Local user context

Personal collaboration and accessibility context is local-only.
If the operator explicitly supplies a profile, read it from
`${CODEX_HOME}/local-context/USER_PROFILE.md` outside this repository.
Do not create that file, copy it into Git or synchronise it by default.
Its absence is not a blocker. Use the current request and repository
evidence. Credentials belong in 1Password; sessions stay per-machine.
